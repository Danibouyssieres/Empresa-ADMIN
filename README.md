# Movilidad y Salud Asistida - Empresa-ADMIN

Aplicación web para la gestión de servicios de traslado y asistencia clínica TENS.

## Estructura
- index.html: Archivo principal de la aplicación optimizado para despliegue automático en Vercel.
- Movilidad y Salud Asistida.html: Archivo fuente original del sistema.

## Despliegue en Vercel
1. Ingresa a [Vercel](https://vercel.com).
2. Haz clic en **Add New...** > **Project**.
3. Conecta e importa el repositorio de GitHub: Danibouyssieres/Empresa-ADMIN.
4. En la configuración del proyecto, deja las opciones por defecto (Framework Preset: **Other**).
5. Haz clic en **Deploy**.
